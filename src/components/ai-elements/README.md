# AI Elements

Conversation, message and suggestion components were installed from the official AI Elements registry at https://registry.ai-sdk.dev on 2026-09-26. The message component uses Streamdown. The icon-sm button size was adapted to this repository's existing iconSm variant. Supporting shadcn components were installed from its official registry and their import paths adapted to this repository.

These components are bundled by the main app. Run `npm ci` and `npm run dev` from the repository root; no separate registry installation or service is needed for rendering. To send assistant requests, follow [service setup](../../../server/README.md). Editor shortcuts and provider configuration are documented in the [root README](../../../README.md).
